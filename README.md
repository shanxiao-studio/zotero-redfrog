## 功能

- “一键更新“ 文献指标（分区、影响因子等）
- 增加“出版社/会议名称“列，根据文献类型分别显示
- 增加“分区“列，显示文献的不同分区信息
- 增加“引用数“列，并入 [Google Scholar citation Count](https://github.com/justinribeiro/zotero-google-scholar-citation-count) 功能
- 增加“评分“列，为文献评分
